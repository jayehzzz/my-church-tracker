For this sequential programme, use the saved project directly. An agent can establish a feature branch while preserving current files. Keep completed work and task documents available to later tasks; do not silently start again from an older commit.

Read this short index and the selected brief. Each brief contains the objective, useful starting points, and completion checks. The earlier review is evidence to consult as needed, not a requirement to re-audit every file.
